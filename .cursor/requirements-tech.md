# 农业机械试验鉴定数智化 — 技术要求摘要（采购指标）

> 用途：新会话直接贴入/引用。对应前端 `ys-front` 的「1+2+5」布局。

## 2. 定型资料数据智能再造平台（`rebuild`）

### 2.1 子系统与能力要点

**A. 异构数据智能量化**
- 定型资料/历史试验/标准/文献统一录入管理
- 文本/图像/表格结构化解析（语义、OCR、行列识别）
- 即时解析 / 暂存；批量解析；上传与解析实时进度
- 去噪归一（页眉页脚等）；多格式规整
- 版式分析（单/双栏、标题层级、图表）；按阅读序转可编辑文本
- 自定义切分（章节/字符等）+ 实体关系抽取
- 多模态大模型 + OCR + ASR；中英双语；印刷体/繁体/手写/复杂表
- **三栏视图**：左结构化目录 / 中审核编辑 / 右源文件；联动导航
- 解析结果 CRUD；实体边界/类型编辑与手动画框；章节层级可调
- 语义向量化；导出 JSON/DOCX/Markdown/PDF/TXT
- 多模态存储；数据统计工作台（上传/审核/存储）

**B. 关键指标定向抽取**
- 解析：原文、概要、标签、导航、实体（贴合知识库主题）
- 意图推断 → 解析偏好提示词；无意图时用预制通用模版
- 条目化实体识别（文档/音视频/图片）；按模态组织解析偏好
- 性能参数/技术指标智能抽取；分类 CRUD + 章节自动打标审核
- 自定义抽取配置（范围/类型/结果格式）
- 预览模式 / 审核模式；多类农机精细化人工审核
- 指标原文追溯；标准化建模与自动语义标注

**C. 履历知识库构建**
- 全生命周期归类（研发/性能试验设计/鉴定/验收等）
- 技术状态、变更、问题归零、关键事件全程记录
- 图谱：「农机—指标—试验—事件」；三元组 + 融合
- 结构化组织 + 可视化；手动建节点/关系/事件；schema 可改
- 批量上传；表格/文本构图；字典推荐与去重
- 二/三维展示；搜索筛选编辑导入导出；融合节点组推荐
- 分角色权限；压缩包导入导出；批量删除二次确认
- 可扩展结构体系；节点类型（属性/颜色/图标）；关系类型（因果/条件/组成等可扩展）；Schema 可视化预览

**D. 能力牵引态势综合展示**
- 技术状态发展链 + 事件时间轴；原文回溯、阶段对比、变更影响
- 能力评估可视化（雷达/矩阵/柱状；打击/机动/防护等）
- 任务/资源/环境综合态势；试验问题与结果快速定位

**E. 面向智能服务的多维数据再造**
- 平台级 / 个性化知识卡片（参数卡、方法卡等）；专题多模态文档 + 溯源 + 下载
- 核心要素自动识别与关系挖掘；实体/关系/事件组合检索 + 语义扩展
- 动态检索策略与排序权重；意图识别 + 图谱检索 → 可追溯答案
- 全文+向量混合、重排、问题改写与对话补全
- 业务问询推理（溯源/推理/关联/时序/时空）；标准化服务接口
- 推理链路融合检索 + 结构化结果；本体与知识抽取融合统一实体库

### 2.2 性能指标

| 项 | 要求 |
|----|------|
| 单文档上传 | ≥100MB / ≥1000 页 |
| 单图 / 音视频 | ≥30MB / ≥100MB |
| 批量上传 | ≥50 篇且总容量 ≥500MB |
| 50 页向量化 | ≤15s |
| 音视频解析 | ≤5s/MB |
| 图片解析 | ≤10s/MB |
| OCR（印刷体+有线表） | ≥95% |
| 语音转写 | ≥85% |
| 实体抽取 | ≥85%；节点类型 ≥100 |
| 关系抽取 | ≥75%；关系类型 ≥200 |

## 3. 探针设计与智能定位平台（`probe`）

### 3.1 子系统

**A. 多模态体系知识发现**
- 与资源库/再造平台打通；预处理（解析、去噪、对齐）
- 对接 CSV/TXT/PDF/Word/图像等；分词、实体、语义标注、关联匹配
- 跨应用对接任务控制：实时/定时同步、增量更新、定时配置
- ≥5 种解析算法；多条件精准检索 + 导出/第三方对接

**B. 增量式探针推理图谱**
- 探针 CRUD（应用范围、定位维度等）
- 问题/数据/时间/原因/处置/经验 → 实体关系属性图谱
- 去重优化；专家编辑修正；增量更新

**C. 探针数据智能解读**
- 异常根因分析（图谱+历史+专家+大模型方案）
- 可视化成因与趋势；解读报告自动生成、编辑、导出

**D. 智能探针定位**
- 推理思维链：总案/大纲/报告中异常指标、节点、合规风险定位
- 思维链可视化（排查过程与依据）

### 3.2 性能
- 探针数量 ≥ **10**
- 指标名/值/试验结果等实体识别准确率 ≥ **80%**

## 4. 智能试验设计与资源推荐平台（`design`）

### 4.1 子系统

**A. 试验方案智能设计**
- AI + 历史案例/资源/模板 → 方案初稿，可编辑
- 案例与资源入库、检索（关键词/多条件）、版本管理与在线查看
- 标准模板库（上传/更新/删除）
- 人工校核 + 多轮自然语言优化

**B. 数字试验编码生成**
- ≥3 语言代码生成：Python / C++ / MATLAB
- 多轮对话纠错（语法/逻辑）；规范注释生成

**C. 试验资源表征与聚类**
- 从历史文档提取资源（文本/图表/图像+OCR）→ 结构化
- 向量库构建；资源知识图谱；按属性/用途/规格聚类
- 资源信息迭代更新与校验

**D. 任务匹配与智能推荐**
- ≥2 类相似度算法匹配历史资源；图文/列表展示
- 多轮交互提升准确率；推荐资源溯源历史案例

**E. 试验数据智能分析**
- 样本参数研判（偏差大、数量不足等）；缺失补全、噪音消除

### 4.2 性能
- 图像 OCR 准确率 ≥ **70%**
- （总体）试验因子 ≥20；推荐算法 ≥3

## 5. 领域文档自动编写与审校平台（`doc`）★ 演示重点

### 5.1 四个系统（与前端一致）

| 系统 | 核心能力 |
|------|----------|
| **归集** | 多源异构归集（≥6 格式：Word/PDF/WPS/图/扫描/压缩包）+ OCR；智能分类标签；本体建模；文书传递关系；实体类型抽取；实体约束网络；跨文书术语同义消歧；自定义审查策略；领域图谱一致性验证；知识资产/向量化分库；知识服务 API |
| **试验文档设计** | 标准化模板库（自定义/规则绑定/原子条款/权限/版本同步）；提纲智能生成与层级增删改；知识驱动生成与润色（含公文模板）；生成全过程溯源与版本、一键跳原文/规则 |
| **核文勘误与逻辑审查** | 规则建模与模板联动版本；NL→可执行规则；标准上传解析成模板；多策略融合审查（语义/本体/图谱）；跨文档联合审查（总案/大纲/报告等冲突比对、风险等级、一致性链路图）；多智能体协同；专业技能包；标准化审查（语法/规范/逻辑/语义/知识库增强）；结果可视化批注与建议；审查留痕理由链；加密导入导出迁移 |
| **评审报告智能生成** | 审查成果归集映射填模板；多场景报告生成（Word/PDF）；合规校验与链路溯源 |

### 5.2 演示镜头对应（已落地第三部分）
- 提纲设计 → 知识驱动生成初稿 → 生成过程追踪 → 多策略审查 → 文档类型归档（M23–M28）
- UI：虚线框 + Element Plus（见 `ys-form-ui.mdc` P）

### 5.3 性能
| 项 | 要求 |
|----|------|
| 术语库类型 | ≥10 种；术语 ≥10000 |
| 审查规则 | ≥6 个农业分类；规则类型 ≥10；规则 ≥1000 |
| 审查模版 | 领域文档 ≥25；内部公文 ≥6；公文本体 ≥20 |
| 跨文档审查 | ≥6 类文档；策略 ≥5；实体类型 ≥10；关系 ≥20；实体 ≥100 |
| （总体） | 单文档 ≥200 页 |

## 6. 知识深度挖掘与技术研判平台（`insight`）

### 6.1 子系统

**A. 技术创新点智能抽取**
- 多格式科技文献分类收录（解析/OCR/清洗）
- 长上下文：跨段章节创新点关联与指代消解
- 定位创新高发区；抽取主体/动作/细节/效果；多维语义标注 → 标准 JSON

**B. 创新点聚类分类**
- 语义向量化；余弦相似度；K-Means、词共现等多种聚类（总体 ≥3）
- 三级技术体系（原理/试验类型/应用领域）；技术体系知识图谱可视化

**C. 技术研判**
- 研判模板管理与章节样式自定义；按任务/分类/决策层级智能推荐
- 按模板自动组装成熟度/趋势/优先级/路径/高价值方向；图表与摘要
- 在线预览编辑多格式导出；方案查重 ≥6 维；创新点相似度 + 立项溯源；结论导出

### 6.2 性能
- 领域知识图谱实体节点 ≥ **10000**

## 7. 大模型训推平台（`llm`）

### 7.1 子系统
- **专域预训练**：数据集 CRUD；清洗解析打包（多格式）；预览；绑定训练任务；微调数据生成；参数配置；自动标签；推理任务管理与标签筛选
- **置信度评估**：过程可视化、多次采样、多模型概率分布、人工校核；多维加权综合置信度；强弱项识别
- **细粒度微调**：专家知识注入；监控调策略；≥3 类基座、≥32B；LoRA；增量微调与一键启动
- **模型管理**：训练→评估→发版→部署→下线；版本对比回滚；API；开源+微调统一；vLLM（Qwen/GLM 等）
- **量化推理**：多量化程度测评比对；按算力/质量推荐
- **智能提示模板**：检索/生成/入库/分类优化
- **评估与调试**：ROUGE/BLEU/BERTScore/Accuracy/F1 + 自定义；在线调试温度/TopP/TopK；指标 CRUD 与版本

### 7.2 性能
- ≤32B：加载 ≤5min；服务启动 ≤2min
- 输入 256 token：首 token ≤3s；单卡 ≥18 token/s

## 8. 专用智能体自动化编排平台（`agent`）

### 8.1 子系统
- **工作流编排**：可视化拖拽；组件含问题分类、条件分支、迭代/循环、代码执行、数据转换、变量聚合、文档提取、赋值、参数提取、HTTP、列表操作等（≥14）
- 节点 I/O 校验/默认值/映射；单组件调试与日志
- 知识库/大模型/插件集成；AI 能力 API 封装；服务监控；按角色权限
- **工具调用**：工作流封装为智能体上下线；Web/接口第三方集成
- **插件扩展**：Python/Java；MCP + HTTP/TCP；注册审核上下线；调试日志；权限
- **模块化构建**：工作流封装可复用模块；嵌套/跨智能体调用与参数映射

### 8.2 性能
- 编排组件 ≥ **14**；服务并发 ≥ **10**；调度时延 ≤ **3s**（总体）

## 9. 领域资源库（资源库）

### 9.1 功能要点
- 多源异构汇聚入库；去噪归一与多模态治理
- 自定义业务图谱本体自动构图 + 可视化；人工审核原文溯源
- 领域分类（初始五类：通识、定型资料、作战运用、研究成果、试验资料）+ 大模型自动分类
- 多维智能检索（模态/标签/语义/图谱）
- 标注清洗工具扩展接口；统一数据调用标准接口
- 三级库：原始库 / 结构化基础库 / 推理知识库；多层级关联与追溯
- 个人/团队知识库（批量导入、权限、隔离、版本）
- QA 库 CSV/JSON；图谱可视化管理
- 用户/部门/对话/服务监控/许可证全生命周期
- 多模态解析向量检索 → 智能问答（文/图/音视频融合）
- 问题编辑重答；对话轨迹与版本比对；快速复制复用
- 试验总案/大纲/报告等标准化文档存储与关联

### 9.2 性能

|----|------|
| 规模 | 知识库 ≥1000；单库文档 ≥10000；同时使用 ≥200 |
| 存储（总体） | ≥10TB |
| 100 组历史对话检索 | ≤3s |
| 多轮问答上下文 | ≥5000 字符 |
| 1万节点图谱召回 | ≤5s |
| FAQ 检索 | ≤2s，准确率 ≥80% |
| 1000 篇文档库召回 | ≤5s |
